

## Project Title
EconoCausal : Dynamic Pricing via Double Machine Learning

## Project Description
EconoCausal is a Causal AI project that estimates how different discounts affect customer purchasing behavior. It uses Double Machine Learning to estimate Individual Treatment Effects (ITE) and optimization techniques to allocate a limited marketing budget.

## Problem Statement

Traditional machine learning models often predict customer behavior but cannot, by prediction alone, establish whether a discount causes a customer to make a purchase. EconoCausal aims to estimate the causal impact of different discounts to support better marketing decisions.
